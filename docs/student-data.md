# 初期生徒マスタ

2026年11月26日に確認した日本版の初期マスタは26件（通常衣装25件・衣装違い1件）。通常版には「通常」を付けず、衣装違いは別IDで記録できる。日本版の全実装生徒の総数と網羅性は未確認。名称、学園、役割、配置、攻撃・防御、初期の星、募集限定区分を短い事実項目として手作業で登録した。限定区分は期間限定募集の有無で、配布のノノミは限定募集に含めない。生徒IDはこの台帳内の固定ID。ゲーム側の ID と独立している。
